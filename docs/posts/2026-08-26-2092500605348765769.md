<pre class="x-verbatim">i think to build mastery in anything you need to put in the hours and do something a thousand times. there&#x27;s no substitute for that. if you build a compiler 1000 times, you will definitely learn something.

the question i think, is whether that mastery in understanding the code still matters when agents do all the work. if you buy the &quot;coding is solved&quot; thing, it probably doesn&#x27;t, and you&#x27;re better off learning the higher level skill of managing agents. we are moving up an abstraction level, and while understanding the code today does give you some edge in managing agents, who&#x27;s to say what the future looks like? 

personally, i think that there is still a lot of alpha from understanding how computers, compilers, programming languages, ui frameworks, etc work. even if agents are writing all the code, you still need to know what to ask in order to build truly interesting software (ie not just crud apps). agents make the process of writing software easier, but you can only prompt what you can imagine, and if you haven&#x27;t had that experience, it&#x27;s difficult to articulate something you&#x27;ve never seen or done. 

so i still feel like learning these things matter, if only to be able to put interesting thoughts into words so that your agent can build them</pre>
